### `sweep.sh`
```bash
#!/usr/bin/env bash
# Corpus sweep for task 023 slice 2. Builds every corpus project with a given CLI into a fresh
# `git archive` copy and collects the emitted assemblies.
#   * `.tests.nl` projects go through `nlc test` (`nlc build` under-measures them, STATUS §1).
#   * The copy is given a SYMLINK to the real src/NSharpLang.Cli output, because 23 of the corpus
#     projects name `../../../src/NSharpLang.Cli/bin/...` as a repo-relative `dll:` dep and a
#     `git archive` copy has no such directory (B15's gotcha). Without it, coverage is 49/73.
# Usage: sweep.sh <cli-dll> <arm-name>
set -uo pipefail
CLI="$1"; ARM="$2"
H=/private/tmp/nsharp-023s2-writer-harness
SRC=/private/tmp/nsharp-agent-wt/023-s2
TREE="$H/trees/$ARM"; OUT="$H/out/$ARM"
rm -rf "$TREE" "$OUT"; mkdir -p "$TREE" "$OUT/asm"
(cd "$SRC" && git archive HEAD) | tar -x -C "$TREE"
mkdir -p "$TREE/src/NSharpLang.Cli/bin/Debug"
ln -sfn "$SRC/src/NSharpLang.Cli/bin/Debug/net10.0" "$TREE/src/NSharpLang.Cli/bin/Debug/net10.0"
TOTAL=0; BUILT=0
: > "$OUT/transcript.txt"
while IFS= read -r pj; do
    d=$(dirname "$pj"); rel=${d#"$TREE"/}
    case "$rel" in src/*) continue;; esac
    TOTAL=$((TOTAL+1))
    if ls "$d"/*.tests.nl >/dev/null 2>&1; then CMD=test; else CMD=build; fi
    o=$(cd "$SRC" && dotnet "$CLI" $CMD --project "$d" 2>&1); rc=$?
    printf '=== %s cmd=%s rc=%s\n' "$rel" "$CMD" "$rc" >> "$OUT/transcript.txt"
    printf '%s\n' "$o" | tail -4 >> "$OUT/transcript.txt"
    [ $rc -eq 0 ] && BUILT=$((BUILT+1))
done < <(find "$TREE/examples" "$TREE/tests" "$TREE/templates" -name project.yml -not -path '*/obj/*' -not -path '*/bin/*' | sort)
while IFS= read -r f; do
    rel=${f#"$TREE"/}; safe=$(printf '%s' "$rel" | tr '/' '_')
    cp "$f" "$OUT/asm/$safe"
done < <(find "$TREE" -path '*/bin/*' -name '*.dll' -type f -not -name 'NSharpLang.Runtime.dll' | sort)
echo "ARM=$ARM TARGETS=$TOTAL BUILT=$BUILT ASSEMBLIES=$(ls -1 "$OUT/asm" | wc -l | tr -d ' ')"
```

### `corpus-compare.py`
```python
#!/usr/bin/env python3
"""Whole-PE compare over CORPUS OUTPUT ONLY.

The sweep's dll-dep symlink drags the compiler's OWN binaries (Compiler.dll,
BootstrapServices.dll, Cli.dll) into each project's bin. Those differ between arms BY
CONSTRUCTION -- the two arms ARE two compilers -- so counting them reports a false diff.
"""
import os, sys
sys.path.insert(0, '/Users/spencer/nl98keep/harness')
from nl98_ilnorm import normalise
H = '/private/tmp/nsharp-023s2-writer-harness'
SKIP = ('Compiler.dll', 'NSharpLang.Compiler.BootstrapServices.dll', 'NSharpLang.Runtime.dll',
        'Mono.Cecil.dll', 'NSharpLang.Build.Tasks.dll', 'Cli.dll', 'NSharpLang.LanguageServer.dll')
PRE = ('Microsoft.', 'Swashbuckle.', 'xunit.', 'System.', 'Newtonsoft.', 'YamlDotNet')
def corpus(n):
    b = n.split('net10.0_')[-1].replace('tests_', '', 1)
    return b not in SKIP and not b.startswith(PRE)
a, b = os.path.join(H, 'out/pre/asm'), os.path.join(H, 'out/post/asm')
fa, fb = set(os.listdir(a)), set(os.listdir(b))
common = sorted(x for x in (fa & fb) if corpus(x))
same, diffs = 0, []
for n in common:
    na, _ = normalise(open(os.path.join(a, n), 'rb').read())
    nb, _ = normalise(open(os.path.join(b, n), 'rb').read())
    if na == nb: same += 1
    else: diffs.append(n)
print("CORPUS ASSEMBLIES COMPARED=%d SAME=%d IL_DIFFS=%d ONLY_PRE=%d ONLY_POST=%d"
      % (len(common), same, len(diffs),
         len([x for x in fa - fb if corpus(x)]), len([x for x in fb - fa if corpus(x)])))
for d in diffs: print("  DIFF", d)
```

## 4. A harness that is LOST and must be rebuilt for S2.3 onward

`nl23_bodykey.py`, the METHOD-BODY KEY DUMPER built in S2.0, lived in the shared directory
`/private/tmp/nsharp-agent-wt/probes` that another session deleted mid-run; it was never recreated
because (a)-(f) only ever needed whole-PE identity (one writer, so bytes are comparable). **From S2.3
the writer is a second writer and whole-PE identity becomes impossible**, so it must be rebuilt. Its
design, from the S2.0 decode (`decodes/2026-09-03-writer-second-executor-decode.md`), is:

- front-ended by `ilspycmd -il` (zero C# written), which already resolves every token operand to
  `[Scope]Namespace.Type::Member(sig)`;
- KEY = `<declaring type path>::<normalised .method header>`, taken from `ilspycmd`'s own
  `// end of method` / `// end of class` markers -- comments must be read BEFORE they are stripped,
  and the class NAME from the FIRST line of the `.class` declaration, not the joined header;
- VALUE = the opcode sequence with short/long encodings folded (`ldarg.0`/`ldarg.s 0` -> `ldarg 0`,
  `ldc.i4.8` -> `ldc.i4 8`, `br.s` -> `br`, `leave.s` -> `leave`) and branch operands rewritten from
  BYTE OFFSETS to TARGET INSTRUCTION ORDINALS;
- `.maxstack`, the `.locals init` list and the exception-region structure compared but reported
  SEPARATELY, so a maxstack change cannot pass as "no IL diff";
- `--scope exact | scopeless`, where `scopeless` IS the contract-equivalence mapping, with a
  collision guard that reports any full type name seen under two scopes;
- proven non-vacuous by a `selftest` that perturbs one instruction and asserts exactly one key moves.
