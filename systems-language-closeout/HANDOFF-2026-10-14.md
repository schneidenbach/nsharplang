## 5. Operating lessons (do not relearn these)

- **Watch every background job.**
  - Give each job its own watcher, and detect completion from the log's LAST line (`tail -1 | grep '^CODEX_EXIT'`).
    Agents grep other logs, so the sentinel appears mid-file.
  - A missed watcher left a finished batch ungated for about 33 hours.
- **Never kill processes by pattern.** Never `pkill`/`killall` by command pattern, because sibling gates run
  identical command lines. Kill by PID. Never kill a running `test-all.sh` driver: its EXIT trap deletes the tree
  under a live core.
- **Do not touch the integration branch.** `census/merge` and its worktree belong to the integration session.
  Never check it out or commit there.
- **Keep agent worktrees safe.** Agent worktrees went to `/private/tmp/nsharp-agent-wt/<name>`. macOS empties files
  there after about 3 days untouched, so commit WIP and never leave uncommitted work for days.
- **Avoid shared-cache seed collisions.**
  - Seeds with different contents under the same version clobber `~/.nuget/packages/nsharplang.sdk`.
  - Use a private `NUGET_PACKAGES` per run. The plan's W1.4 proposes versioned seeds to end this.
- **What counts as gate evidence.** Before a push, only a fresh `test-all.sh --commit` counts (VS Code-enabled for
  IDE changes). Focused agent runs do not. Agents repeatedly missed:
  - pinned census counts (`compile-time-bench` corpus and the repo-root workspace census)
  - ownership-audit repins (regenerate from `audit --verbose`, never hand-merge)
  - CLI and gate contract tests
  - reflection-by-name lookups of renamed entry points
- **Keep CI and local results consistent.**
  - CI runs Release estates on Linux x64; local is macOS Debug, so hard-coded `bin/Debug` paths break CI.
  - Structural counters must be platform-independent (fixed in `0d3e81633`).
  - A local NativeAOT smoke with the Homebrew .NET pack can fail to link (`libssl` not on the search path).
    Use the repo's official-pack override.
- **Check IDE parity, not self-consistency.** Every visual scenario compares editor diagnostics with `nlc check`. A
  scenario that only checks itself passed while rename silently skipped `*.tests.nl` (fixed in `aab96ac0e`).
