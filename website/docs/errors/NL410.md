# NL410: a default parameter value the compiler cannot evaluate

A default parameter value is not code that runs — it is a **constant stored in metadata** and copied
into each call site that omits the argument. N# accepts only the expressions it can fold to such a
constant, and reports NL410 for everything else.

```n#
func Size(): int {
    return 4
}

func Make(width: int = Size()): int {          // ERROR NL410
    return width
}
```

```text
── [NL410] ERROR ──────────────────────────── Program.nl:5:24 ──

    5 | func Make(width: int = Size()): int {          // ERROR NL410
      |                        ^^^^

The default value for 'width' must be something the compiler can evaluate — use a literal, null, default, or a simple constant
```

The span is on the default expression, not on the parameter. `Size()` is a perfectly good function;
the problem is only that a call cannot be written into metadata.

## Why is this an error?

The CLR stores an optional parameter's default as a literal in the assembly's constant table, and
callers read it from there — the declaring function is never consulted. There is nowhere for
`Size()` to run: not at the call site, which only sees the constant, and not in the callee, which is
never entered with a missing argument. Accepting the syntax would mean silently choosing a different
meaning from the one written.

## How to fix it

Use a literal:

```n#
func Make(width: int = 4): int {
    return width
}
```

When the value genuinely has to be computed, make the parameter nullable, default it to `null`, and
do the work in the body. `??` reads as "the caller's value, or else compute one":

```n#
func Make(width: int? = null): int {
    return width ?? Size()
}
```

## What counts as a constant

The rule is recursive over the expression, and accepts:

- a literal — integral, floating, `decimal`, `char`, `bool`, `string`, or `null`;
- `default`, the zero value of the parameter's type (`when: DateTime = default`);
- a member of the **same enum** the parameter is declared as (`mode: Mode = Mode.Fast`) — a member
  of a *different* enum is refused even though it is equally constant;
- a unary operator applied to a valid default, so `-1` is one;
- a binary operator whose both sides are valid defaults, so `2 * 3` is one;
- an array literal whose every element is a valid default.

Everything else is NL410: a call, a `new` expression, a local, a property, a field, a null-conditional
access. The commonest surprise is `new`, because it reads like a default rather than like work:

```n#
class Box {
    Width: int

    constructor(width: int) {
        Width = width
    }
}

func Make(box: Box = new Box(4)): int {          // ERROR NL410
    return box.Width
}
```

A constant must still be a value of the parameter's type: `size: byte = 300` and `n: int = null`
pass this rule and are then a type mismatch, [NL202](./NL202.md), on the default.

### A struct's static value is not a constant

`DateTime.MinValue`, `TimeSpan.Zero` and `Guid.Empty` read like constants, but each is a static field
read when the program runs, so there is nothing to store in metadata. C# refuses them for the same
reason. The help line names the two spellings that work:

```n#
import System

func Since(start: DateTime = DateTime.MinValue): long {          // ERROR NL410
    return start.Ticks
}
```

```text
help: 'DateTime.MinValue' is read when the program runs, so it cannot be stored as a default. Write '= default' for the type's zero value, or make 'start' nullable, default it to null, and choose the value in the body.
```

`= default` is the struct's zero value — for `DateTime`, `0001-01-01`, which is `DateTime.MinValue`:

```n#
import System

func Since(start: DateTime = default): long {
    return start.Ticks
}
```

Some shapes on the accepted list are ahead of the backend. An arithmetic default (`2 * 3`) and a
combination of enum members (`Options.A | Options.B`) clear this rule and then stop at
[NL103](./NL103.md) during lowering — that is a gap in the code generator, not a second opinion about
constants. A single literal (negative ones included) or a single member is the way through it today.
