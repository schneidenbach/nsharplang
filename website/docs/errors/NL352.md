# NL352: a catch filter cannot await

A `when` expression runs synchronously during the first pass of exception handling. It must decide
whether the clause accepts the exception before the runtime unwinds `finally` blocks, so it cannot
suspend with `await`.

```n#
import System
import System.Threading.Tasks

async func Read(): Task<int> {
    try {
        throw new InvalidOperationException()
    } catch ex: InvalidOperationException when await Task.FromResult(true) { // ERROR NL352
        return 1
    }
}
```

Keep the filter synchronous. Put awaited work in the selected `catch` body, where the handler can
suspend safely:

```n#
async func Read(): Task<int> {
    try {
        throw new InvalidOperationException()
    } catch ex: InvalidOperationException when ex.Message.Length > 0 {
        return await LoadFallback()
    }
}
```
