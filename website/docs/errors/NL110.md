# NL110: invalid preprocessor directive

N# has a small conditional-compilation preprocessor — `#if`, `#elif`, `#else`, `#endif` — and NL110
covers every way of writing one that does not hold together.

```n#
func Greet(): string {
    return "hi"
}
#endif          // ERROR NL110
```

```text
── [NL110] ERROR ───────────────────────────── Program.nl:4:1 ──

    4 | #endif          // ERROR NL110
      | ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

'#endif' directive without a matching '#if'.
```

## Why is this an error?

Conditional compilation decides which lines the compiler sees at all. An unbalanced directive means
the compiler cannot know where a conditional region begins or ends, so it cannot know what your
program is. There is no conservative reading to fall back on.

## How to fix it

Pair the directive, or delete it:

```n#
func Greet(): string {
    return "hi"
}
```

## Every case this code covers

| What you wrote | What the message says |
|---|---|
| `#endif` with no `#if` | `'#endif' directive without a matching '#if'.` |
| `#if` with no `#endif` | `Unterminated '#if' directive: expected a matching '#endif'.` |
| `#else` with no `#if` | `'#else' directive without a matching '#if'.` |
| two `#else` for one `#if` | `Multiple '#else' directives for a single '#if'.` |
| `#elif` after `#else` | `'#elif' directive cannot appear after '#else'.` |
| `#elif` with no `#if` | `'#elif' directive without a matching '#if'.` |
| a condition that will not evaluate | the evaluator's own message |
