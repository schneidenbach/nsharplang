# NL351: a lock body cannot suspend

A `lock` body must complete synchronously. C# forbids both `yield` and `await` inside a lock because
the monitor must not remain held while control is returned to a caller or an asynchronous operation
is suspended. N# reports the suspension point directly; a lock block with no suspension is valid in
an iterator.

```n#
import System.Collections.Generic
import System.Threading.Tasks

async func* Values(gate: object): IAsyncEnumerable<int> {
    lock gate {
        await Task.Delay(1)   // ERROR NL351
    }
    yield 1
}
```

Move awaited work before the lock, then lock only the synchronous work that uses its result. Move a
`yield` after the lock block.
