# NL349: a generic interface named without the arguments it is implemented with

A generic interface has as many slot sets as it has instantiations, so a qualifier naming one has to
say **which**. NL349 is a qualifier whose type-argument list does not match the way the declaration's
interface list writes the interface — most often a generic interface written bare.

```n#
interface IBox<T> {
    Item: T
}

class Probe: IBox<string> {
    Item: string => "boxed"
    IBox.Item: string => "also boxed"       // ERROR NL349
}
```

```text
── [NL349] ERROR ─────────────────────────── Program.nl:7:5 ──

    7 |     IBox.Item: string => "also boxed"       // ERROR NL349
      |     ^^^^^^^^^

'IBox' does not name the interface the way 'Probe' implements it

Suggestion: Write the interface closed, with the same type arguments the declaration's interface list writes — 'IBox<…>'.
```

The type above fills `Item` the ordinary way, so NL349 is the only report. A bare generic qualifier
on the type's ONLY implementation of a member also leaves the slot unfilled, so
[NL325](./NL325.md) appears beside it on the class header — two reports for one mistake, which is
what you will usually see.

## Why is this an error?

`IReadOnlyCollection<string>` and `IReadOnlyCollection<int>` are two interfaces with two `Count`
slots, and a type may implement both. A bare `IReadOnlyCollection` names neither, so there is no slot
to fill and no `MethodImpl` row to write.

Writing it **closed** is also what metadata does: the emitted CLR name of the member is the interface
spelled out with its arguments —
`System.Collections.Generic.IReadOnlyCollection<System.String>.Count` — exactly as a C# compiler
spells it, so a consumer in any .NET language finds the member where it expects to.

## How to fix it

Copy the spelling from the interface list:

```n#
class Probe: IBox<string> {
    IBox<string>.Item: string => "boxed"
}
```

The same rule reaches the framework's own interfaces — `IReadOnlyCollection<string>.Count`, not
`IReadOnlyCollection.Count`:

```n#
class Bag: IReadOnlyCollection<string> {
    items: List<string> = new List<string>()

    IReadOnlyCollection<string>.Count: int => items.Count
}
```

A NON-generic interface takes no argument list, and the inherited non-generic half of a generic one is
named bare — `IEnumerable<string>` inherits `IEnumerable`, and `IEnumerable.GetEnumerator` is the
canonical explicit implementation:

```n#
class Bag: IReadOnlyCollection<string> {
    func GetEnumerator(): IEnumerator<string> { … }
    func IEnumerable.GetEnumerator(): IEnumerator { … }
}
```
