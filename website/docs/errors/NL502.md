# NL502: this match arm can never be reached

`match` tries its arms in order and stops at the first one that matches. An arm written below
something that already matches every value is dead code — it compiles, and it never runs.

```n#
func Classify(n: int): string {
    return match n {
        _ => "many",
        1 => "one"          // ERROR NL502
    }
}
```

```text
── [NL502] ERROR ───────────────────────────── Program.nl:4:9 ──

    4 |         1 => "one"          // ERROR NL502
      |         ^

This arm can never be reached — the '_' arm on line 3 already matches every value

Suggestion: Move this arm ABOVE the '_' arm on line 3, or delete it. A catch-all belongs last.
```

The message **names the line that already covers it**, because the dead arm is rarely the
mistake — the arm above it is in the wrong place.

## Why is this an error?

Reordering is the commonest way to break a `match`, and it breaks it silently: the program still
compiles, still type-checks, and quietly returns `"many"` for `1`. A rule that only warned would
leave that behaviour shipping. Before this check existed N# accepted the arm and said nothing at
all.

## How to fix it

**Put the catch-all last.** It is the arm that means "everything I have not already handled", so
it only means that when nothing follows it:

```n#
func Classify(n: int): string {
    return match n {
        1 => "one",
        _ => "many"
    }
}
```

## What counts as a catch-all

An **unguarded** arm whose pattern is a bare binding. Both spellings match every value of every
type:

- `_ => ...` — the wildcard, which binds nothing;
- `other => ...` — a plain name, which binds the value and matches it whatever it is.

Everything else covers only part of the domain, so nothing below it is dead on account of it. In
particular:

- **A guarded arm is conditional.** `big when big > 10 => ...` may or may not match, so the arms
  after it are perfectly reachable.
- **A dotted name is a union case**, not a binding. `Result.Success => ...` covers exactly one
  case of one union.
- **A literal, a type pattern, an object pattern** and the rest each cover part of the domain.

## Every dead arm is named

If three arms sit below a catch-all, all three are reported, each pointing at the same line:

```n#
func Classify(n: int): string {
    return match n {
        _ => "many",
        1 => "one",         // ERROR NL502
        2 => "two"          // ERROR NL502
    }
}
```

One report per arm rather than one per `match`: each is a separate line the reader has to move
or delete, and a single diagnostic would leave them to find the rest by hand.
