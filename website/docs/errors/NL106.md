# NL106: missing closing brace

A `{` was opened and never closed. N# reports the position of the **opening** brace, not the end of
the file, because that is the construct you need to look at.

```n#
class Greeter {          // ERROR NL106
    func Greet(): string {
        return "hi"
    }
```

```text
── [NL106] ERROR ───────────────────────────── Program.nl:1:7 ──

    1 | class Greeter {          // ERROR NL106
      |       ^^^^^^^

Missing closing '}'

The type body that started on line 1 is missing its closing brace. I reached the end of the file without finding it.

Hint: Add a '}' to close this type declaration.
```

## Why is this an error?

Brace depth is what tells the parser where a class ends and the next declaration begins. With one
unclosed, everything after it is read as part of the wrong construct, so N# stops rather than
producing a page of consequential errors about code that is fine.

## How to fix it

Close it:

```n#
class Greeter {
    func Greet(): string {
        return "hi"
    }
}
```

## Reading the position

The caret is on the `{` that is still open — the outermost one, if several are. Auto-indentation is
usually the fastest confirmation: reformat the file and the line whose indentation does not return
to zero is the one that never closed.
