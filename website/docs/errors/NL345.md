# NL345: an explicit implementation of an interface the type does not implement

An explicit interface implementation is written with a qualified member name — `func
IEnumerable.GetEnumerator(): IEnumerator { … }` — and the qualifier names the interface whose slot the
member fills. NL345 is a qualifier naming an interface the declaring type does not implement, directly
or through one it does.

```n#
interface IPing {
    func Ping(): int
}

interface IPong {
    func Pong(): int
}

class Probe: IPing {
    func IPing.Ping(): int => 1
    func IPong.Pong(): int => 2       // ERROR NL345
}
```

```text
── [NL345] ERROR ────────────────────────── Program.nl:12:5 ──

   12 |     func IPong.Pong(): int => 2       // ERROR NL345
      |     ^^^^^^^^^^^^^^^^

'Probe' does not implement 'IPong', so it cannot implement 'IPong.Pong' explicitly

Suggestion: Add 'IPong' to the declaration's interface list, or drop the qualifier so this becomes an ordinary member named 'Pong'.
```

## Why is this an error?

The qualifier is not decoration: it selects the slot the member fills, and the compiler writes a
`MethodImpl` row naming that slot. A row naming a method the type does not implement produces an
assembly the CLR **refuses to load** — a runtime failure for a source mistake — so the name is checked
where it is written.

It is also the diagnostic for a typo. A qualifier that names nothing the type implements is much more
often a misspelling than a missing interface, and the message names both fixes.

## How to fix it

**Add the interface**, when the type really does mean to implement it:

```n#
class Probe: IPing, IPong {
    func IPing.Ping(): int => 1
    func IPong.Pong(): int => 2
}
```

**Or drop the qualifier**, when the member is an ordinary one that happens to share a name:

```n#
class Probe: IPing {
    func IPing.Ping(): int => 1
    func Pong(): int => 2
}
```

## An inherited interface counts

A type that writes `IReadOnlyCollection<string>` also implements `IEnumerable<string>` and
`IEnumerable`, so all three may be named:

```n#
class Bag: IReadOnlyCollection<string> {
    func IEnumerable.GetEnumerator(): IEnumerator { … }   // fine: inherited through the list
}
```
