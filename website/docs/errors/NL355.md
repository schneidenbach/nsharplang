# NL355: async lambda in a generic owner

An async lambda inside a generic method or type cannot yet carry its owner's generic parameters
into the generated state machine. Generic async functions, methods, and supported async local
functions work; this diagnostic applies to async lambdas whose surrounding method or type is
generic.

```n#
import System
import System.Threading.Tasks

async func Read<T>(source: Task<T>): Task<T> {
    read: Func<Task<T>> = async () => { // ERROR NL355
        return await source
    }
    return await read()
}
```

Move the async body to a non-generic helper and pass its required values explicitly.
