# NL401: wrong number of arguments

The callable exists and the call passes the wrong number of arguments. N# reports this against the
**name**, not against the argument list, because the name is what identifies the signature you got
wrong — the arguments themselves may each be perfectly good values.

```n#
func Greet(name: string): string {
    return "hello " + name
}

func Use(): string {
    return Greet("world", "again")          // ERROR NL401
}
```

```text
── [NL401] ERROR ──────────────────────────── Program.nl:6:12 ──

    6 |     return Greet("world", "again")          // ERROR NL401
      |            ^^^^^

Function 'Greet' expects 1 argument but got 2

I am having trouble with this function call on line 6:

Hint: The function `Greet` expects 1 argument, but you are
passing 2. You may have passed too many arguments.
```

The count in the message is the number of **required** parameters. A parameter with a default and a
`params` tail both contribute zero to it, so a function declared `Join(sep: string, params items:
string[])` still "expects 1 argument".

## Why is this an error?

N# binds calls at compile time to a single signature. Arity is the first thing that binding
consults, and a call whose arity matches nothing has no signature to check the arguments against —
so continuing would mean guessing which parameter each argument was meant for. NL401 stops at the
first honest answer instead.

## How to fix it

Pass what the signature asks for:

```n#
func Greet(name: string): string {
    return "hello " + name
}

func Use(): string {
    return Greet("world")
}
```

## NL401, NL402 or NL202 — which one you get

Three different mistakes live at a call site, and N# separates them by how many candidates the name
has and by what actually failed:

| Situation | Code | What it underlines |
|---|---|---|
| One candidate, wrong number of arguments | `NL401` | The callable's name. |
| One candidate, right count, wrong argument type | [NL202](./NL202.md) | The offending **argument**. |
| Two or more candidates, none of them match | [NL402](./NL402.md) | The callable's name, plus a list of the overloads. |

The middle row is why a wrong-type argument does not read as an arity problem: with one candidate,
N# already knows which parameter your argument was meant to fill and reports the mismatch there.

## Methods, constructors and optional parameters

NL401 is not limited to free functions. An instance method with a single signature reports it the
same way, underlining the member name rather than the receiver:

```n#
class Greeter {
    func Greet(name: string): string {
        return "hi " + name
    }
}

func Use(greeter: Greeter): string {
    return greeter.Greet()          // ERROR NL401: expects 1 argument but got 0
}
```

Optional parameters shift the boundary rather than removing it. `Greet(name: string, greeting:
string = "hello")` accepts one or two arguments; zero is still NL401, and the message says
`expects 1 argument` because one is the minimum the signature will accept.
