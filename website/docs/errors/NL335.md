# NL335: a lambda whose body is missing the `async` keyword

The delegate this lambda is written for returns a task — `Task`, `Task<T>`, `ValueTask` or
`ValueTask<T>` — and the lambda's body produces something that is not a task. That is what the
`async` keyword fixes: an `async` body's value becomes the task's **result**, so a body that answers
`int` satisfies a `Func<Task<int>>`.

```n#
import System
import System.Threading.Tasks

func readLength(): Func<Task<int>> {
    return () => await Task.FromResult(7)     // ERROR NL335, NL202
}
```

NL202 rides along because the lambda's type is then not the one the function returns; NL335 is the
one that names the fix.

```text
── [NL335] ERROR ────────────────────────────────── Program.nl:6:12 ──

    6 |     return () => await Task.FromResult(7)     // ERROR NL335, NL202
      |            ^

This lambda has to produce 'Task<int>', but its body produces 'int' — it is missing the 'async'
keyword

Suggestion: Write `async` in front of the lambda and its body's value becomes the task's result, or
return a task the body builds itself (for example with `Task.FromResult(...)`).
```

## `await` requires an async body

An `await` expression must be inside an `async` function or lambda; otherwise NL353 points at the
`await` and explains how to fix it. NL335 covers a different conversion error: the target returns a
task, but a non-async lambda's body produces a value of another type. A body that already produces a
task is correct and says nothing:

```n#
func passThrough(): Func<Task<int>> {
    return () => Task.FromResult(7)           // fine — the body IS the task
}
```

## How to fix it

**Write `async`.** The body's value becomes the task's result, and an exception it raises lands on
the returned task rather than on the caller.

```n#
func readLength(): Func<Task<int>> {
    return async () => await Task.FromResult(7)
}
```

**Or build the task yourself.** When the body already has a task in hand, hand that back and drop the
`await`.

```n#
func readLength(): Func<Task<int>> {
    return () => Task.FromResult(7)
}
```
