# NL350: an iterator cannot return a value

An iterator produces elements with `yield`; `return value` is not an iterator exit and is rejected
before code generation. The diagnostic points at the returned expression.

```n#
import System.Collections.Generic

func* Values(): IEnumerable<int> {
    return 42                 // ERROR NL350
}
```

Use `yield 42` to produce the element. Use a bare `return` or `yield break` when the sequence should
stop.
