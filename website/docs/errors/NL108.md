# NL108: missing closing bracket

A `[` was opened and never closed — an index expression, an array type, or an array literal.

```n#
func First(values: int[]): int {
    return values[0          // ERROR NL108
}
```

```text
── [NL108] ERROR ──────────────────────────── Program.nl:2:12 ──

    2 |     return values[0          // ERROR NL108
      |            ^^^^^^

Missing closing ']'

I reached the next line while looking for the closing ']' that matches an earlier '['.

Hint: Every opening bracket '[' needs a matching closing bracket ']'.

Suggestion: Add ']' before starting the next line
```

## Why is this an error?

An index is an expression that must be closed before the enclosing expression can be finished.
`values[0` followed by a newline is not "index zero, obviously"; it is an index whose subscript
expression is still being read, and the next token would be part of it.

## How to fix it

```n#
func First(values: int[]): int {
    return values[0]
}
```

## Where it shows up

- an index expression, `values[i`;
- an array type in a signature, `func Sum(values: int[): int`;
- an attribute, `[trusted(reason: "audited"`  — the attribute's own parens and bracket must both
  close.
