# NL344: a creation that does not set a required member

A member declared `required` must be set by **every** creation of its type. A creation satisfies the
demand by naming the member in its object initializer, or by calling a constructor that carries
`[SetsRequiredMembers]`. NL344 is a creation that does neither.

```n#
class User {
    required Id: string
    required Name: string
    Email: string = ""
}

func make(): User {
    return new User {                 // ERROR NL344
        Id: "u-1"
    }
}
```

```text
── [NL344] ERROR ────────────────────────── Program.nl:8:16 ──

    8 |     return new User {                 // ERROR NL344
      |                ^^^^

'Name' is required by 'User', and this creation never sets it

Suggestion: Name 'Name' in the object initializer — 'new User { Name: … }' — or mark the constructor '[SetsRequiredMembers]' if it sets them itself.
```

When more than one member is missing, all of them are named in one sentence.

## Why is this an error?

`required` is the type saying that a value of it is not meaningful without this member. Without the
check the word would be a comment: the creation would compile, the member would hold `null` or zero,
and the failure would surface far from the line that caused it.

The demand is written into the emitted metadata — `[RequiredMember]` on the member and on the type,
and `[CompilerFeatureRequired("RequiredMembers")]` on every constructor — so a C# caller of your
assembly is held to the same rule by its own compiler (C# reports it as CS9035). N# reads those same
attributes on types it consumes, so a C# type's `required` members are demanded of N# creations too.

## How to fix it

**Name the member in the initializer:**

```n#
return new User {
    Id: "u-1",
    Name: "Alice"
}
```

**Or let a constructor promise to set them.** `[SetsRequiredMembers]` is that promise, and it is what
makes a creation that names nothing legal:

```n#
import System.Diagnostics.CodeAnalysis

class Preset {
    required Kind: string

    [SetsRequiredMembers]
    constructor(kind: string) {
        Kind = kind
    }
}

preset := new Preset("fast")          // no initializer needed
```

Use it only when the constructor really does set every required member: the attribute switches the
check off for that constructor, it does not verify it.

## Inherited demands

A `required` member declared by a base type is demanded of every creation of a derived type:

```n#
class Node {
    required Key: string
}

class Leaf: Node {
    Payload: int = 0
}

leaf := new Leaf {
    Key: "k"                          // the base's demand, satisfied here
}
```
