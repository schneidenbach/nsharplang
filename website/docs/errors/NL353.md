# NL353: `await` outside an async function or lambda

An `await` expression suspends an async body until its awaiter completes. The enclosing function or
lambda must be marked `async` so the compiler can generate its resumable state machine.

```n#
import System.Threading.Tasks

func readValue(): Task<int> {
    return await Task.FromResult(7) // ERROR NL353, NL202
}
```

```text
'await' can only be used inside an async function or lambda

Suggestion: Add `async` to the enclosing function or lambda, or remove `await` and return the task directly
```

Add `async` when the body needs the awaited result:

```n#
async func readValue(): Task<int> {
    return await Task.FromResult(7)
}
```

If the body only passes a task through, return it directly and omit `await`:

```n#
func readValue(): Task<int> {
    return Task.FromResult(7)
}
```

`await` remains forbidden in catch filters ([`NL352`](./NL352.md)) and inside `lock`
([`NL351`](./NL351.md)).
