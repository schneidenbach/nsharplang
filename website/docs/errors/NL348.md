# NL348: a modifier word on an explicit interface implementation

An explicit interface implementation is `private`, `final`, `virtual` and `newslot` **by
construction**. There is no accessibility for a word to state and no slot for `static`, `virtual`,
`override`, `abstract` or `sealed` to change, so writing one is an error rather than a no-op.

```n#
interface IPing {
    func Ping(): int
}

class Probe: IPing {
    public func IPing.Ping(): int => 1        // ERROR NL348
}
```

```text
── [NL348] ERROR ────────────────────────── Program.nl:6:12 ──

    6 |     public func IPing.Ping(): int => 1        // ERROR NL348
      |            ^^^^^^^^^^^^^^^^

'public' cannot be written on the explicit interface implementation 'IPing.Ping'

Suggestion: Remove 'public'. An explicit interface implementation is private, final and virtual by construction — it is reached only through 'IPing', so there is no accessibility to state and no slot for 'public' to change.
```

## Why is this an error?

The whole point of the form is that the member is reachable **only** through the interface.
`probe.Ping()` does not find it; `(probe as IPing).Ping()` does. A `public` on it would be a promise
the metadata contradicts, and N#'s casing convention does not apply either — a capital letter says
"exported" about a member the type does not expose at all.

`static` is refused for a different reason: a static method occupies no virtual slot, so there is
nothing for a `MethodImpl` row to name.

## How to fix it

Remove the word:

```n#
class Probe: IPing {
    func IPing.Ping(): int => 1
}
```

If you wanted a member that is *also* callable on the type, write an ordinary one — it fills the slot
implicitly, by name and signature:

```n#
class Probe: IPing {
    func Ping(): int => 1             // implicit: on the type AND through IPing
}
```
