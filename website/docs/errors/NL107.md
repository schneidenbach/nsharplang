# NL107: missing closing paren

A `(` was opened and never closed — an argument list, a parameter list, or a parenthesised
expression. N# points at the opener.

```n#
func Greet(name: string): string {
    return "hello " + name
}

func Use(): string {
    return Greet("world"          // ERROR NL107
}
```

```text
── [NL107] ERROR ──────────────────────────── Program.nl:6:12 ──

    6 |     return Greet("world"          // ERROR NL107
      |            ^^^^^

Missing closing ')'

I reached the next line while looking for the closing ')' that matches an earlier '('.

Hint: Every opening parenthesis '(' needs a matching closing parenthesis ')'.

Suggestion: Add ')' before starting the next line
```

## Why is this an error?

Until the call is closed, the parser cannot know whether the next line is another argument or the
next statement. `Greet("world"` followed by `}` could be a one-argument call missing its paren or a
two-argument call missing its second argument, and N# will not pick one for you.

## How to fix it

```n#
func Greet(name: string): string {
    return "hello " + name
}

func Use(): string {
    return Greet("world")
}
```

## Where it shows up

- a call whose closing paren was deleted with the argument it followed;
- a parameter list broken across lines with the closer lost in an edit;
- a parenthesised condition — `if (a && b` — where the inner parens were rebalanced by hand.
