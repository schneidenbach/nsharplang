# NL803: this type has no instances

Some types exist to be *derived from*, *implemented*, or *called through* — never to be
constructed. An `abstract class` declares a shape with a piece missing, an `interface` declares
a promise with no body at all, and a static class holds only members that belong to the type
itself. `new` on any of the three asks for an object that cannot exist.

```n#
abstract class Shape {
    func Area(): double {
        return 0.0
    }
}

func Make(): Shape {
    return new Shape()          // ERROR NL803
}
```

```text
── [NL803] ERROR ──────────────────────────── Program.nl:8:16 ──

    8 |     return new Shape()          // ERROR NL803
      |                ^^^^^

Cannot create an instance of abstract class 'Shape'

Suggestion: Construct a concrete subclass — `class ConcreteShape : Shape { ... }` — and write `new ConcreteShape()` here, or remove `abstract` from `Shape` if it is meant to be constructed directly.
```

The squiggle sits under the **written type name**, not under the whole `new` expression: the
name is the part of the line that has to change.

## Why is this an error?

The CLR refuses the allocation. `newobj` on an abstract type throws `MemberAccessException` at
run time, and there is no arrangement of later code that makes it succeed — so a compiler that
accepts the line has only moved the failure to a worse place. Before this check existed, N#
accepted `new Shape()` in silence and `nlc check` reported `ok: true` on a project that could
not run.

## How to fix it

**Construct a concrete subclass.** This is almost always what was meant — the abstract class is
the *kind* of thing, and the subclass is a particular one:

```n#
abstract class Shape {
    func Area(): double {
        return 0.0
    }
}

class Circle : Shape {
    func Radius(): double {
        return 1.0
    }
}

func Make(): Shape {
    return new Circle()
}
```

**Or drop `abstract`**, if the class was only marked abstract out of habit and does have
sensible instances of its own:

```n#
class Shape {
    func Area(): double {
        return 0.0
    }
}

func Make(): Shape {
    return new Shape()
}
```

## Interfaces

An interface has no bodies to run, so `new` on one is the same mistake with a different word:

```n#
interface Greeter {
    func Greet(): string
}

func Make(): Greeter {
    return new Greeter()        // ERROR NL803
}
```

```text
── [NL803] ERROR ──────────────────────────── Program.nl:6:16 ──

    6 |     return new Greeter()        // ERROR NL803
      |                ^^^^^^^

Cannot create an instance of interface 'Greeter'

Suggestion: Construct a class that implements it — `class MyGreeter : Greeter { ... }` — and write `new MyGreeter()` here.
```

Write a class that implements it and construct that:

```n#
interface Greeter {
    func Greet(): string
}

class English : Greeter {
    func Greet(): string {
        return "hello"
    }
}

func Make(): Greeter {
    return new English()
}
```

## Static classes

A static class is `abstract sealed` in metadata — a shape the CLR guarantees can never have an
instance. `Console`, `Math`, `File` and `Path` are all static, and N# names them as what the
reader would call them rather than as what the metadata says:

```n#
import System

func Out(): object {
    return new Console()        // ERROR NL803
}
```

```text
── [NL803] ERROR ──────────────────────────── Program.nl:4:16 ──

    4 |     return new Console()        // ERROR NL803
      |                ^^^^^^^

Cannot create an instance of static class 'Console'

Suggestion: `Console` is a static class and has no instances. Call its members directly, as `Console.Member(...)`.
```

Call the member you wanted straight off the type:

```n#
import System

func Out() {
    Console.WriteLine("hello")
}
```

## What NL803 does not report

- **An array of an abstract element type.** `new Shape[](4)` creates four empty slots and no
  instance of `Shape` at all, so it is legal and silent.
- **A closed generic over a concrete definition.** `Holder<T>` is instantiable exactly when its
  own declaration is; the report opens the instantiation first and judges the definition.
- **A target-typed `new`** with no written type name. It adopts the type of the slot it is
  being assigned to, and whatever declared that slot is what has to be right.
- **External types the analyzer could not resolve.** An unresolved name is
  [NL201](./NL201.md)'s report, not this one.
