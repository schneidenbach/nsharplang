# NL354: generic async-local state-machine contexts are unsupported

N# can preserve generic parameters on async functions and generic async local functions in
synchronous owners. A generic async local function inside an async owner is not supported yet: its
state machine must carry the owner's method or type parameters along with the local function's own
parameters. A non-generic async local function inside a generic async method or type has the same
limitation.

```n#
import System.Threading.Tasks

async func read<T>(source: Task<T>): Task<T> {
    async func local(value: Task<T>): Task<T> { // ERROR NL354
        return await value
    }
    return await local(source)
}
```

The diagnostic points at the local function name. Move the async local function to a non-generic
owner, or remove its own type parameters when the owner is non-generic. A generic async local
function under a synchronous generic owner remains supported:

```n#
func read<T>(source: Task<T>): Task<T> {
    async func local(value: Task<T>): Task<T> {
        return await value
    }
    return local(source)
}
```
