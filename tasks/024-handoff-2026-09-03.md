## 2. Procedures that worked (copy them)

**Merge + gate + push (per landing or batch of landings):**

1. `git merge --no-ff <stream tip>` in the main checkout. If both sides repinned the ratchet: keep, per differing
   row, the side that SHRANK the file (ceilings never rise), take either side of the head, then run
   `dotnet <Cli.dll> test --project tests/native/ownership-audit --verbose`; `OWN005` prints a file's observed
   fingerprint, `OWN008` prints the observed head — paste them into both keys and re-run until 18/18.
2. **Rebuild the CLI** (`dotnet build src/NSharpLang.Cli/Cli.csproj`) before running native projects on a merged tree;
   a stale `Cli.dll` made two green projects look red on 2026-09-03. Pre-check the projects the merged streams touch
   (`ownership-audit`, `error-docs-contract`, `diagnostic-honesty`, `analyzer-clean-source`, `lsp-lifetime`) and the
   root format check.
3. Pause every agent (they reply with worktree, tip, clean yes/no). Byte-copy:
   `rsync -a --delete --exclude='.claude/worktrees' --exclude='artifacts/from-worktrees' <repo>/ /private/tmp/gate-<stamp>/tree/`,
   then `git checkout -q -- .` in the copy, `export DOTNET_SYSTEM_NET_DISABLEIPV6=1`, `./scripts/test-all.sh --commit`.
   Never kill the gate driver (its EXIT trap deletes the tree under the running core). `pgrep -fl test-all-core.sh`
   first: another session's gate means wait.
4. On green: move STATUS §1 Cursor + Baselines to the gated sha, `git push origin systems-language` from the main
   checkout (never through `tail`; braces around `${SHA}` in any refspec — zsh reads `$SHA:r` as a modifier), resume
   the agents with the gated sha, `rm -rf` the gate copy's tree (keep `gate.log`).
